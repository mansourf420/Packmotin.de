# Packmotin.de

Website von Packmotin – Fulfillment & Content für kleine und mittlere Unternehmen.

Reine statische Seite (HTML/CSS/JS), kein Build-Schritt. Lokal ansehen:

```bash
python3 -m http.server 8000
# dann http://localhost:8000 öffnen
```

- `index.html` – Startseite
- `impressum.html`, `datenschutz.html` – Pflichtseiten (Platzhalter ausfüllen!)
- `styles.css`, `script.js`
- `assets/` – Logo-Varianten, Favicon, lokal eingebundene Schriften (Archivo, Inter; SIL OFL)
